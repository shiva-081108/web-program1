# Week 04 React Project

## Overview

This project contains two React applications built as part of Week 04:

1. To-Do App
2. Notes App

The project demonstrates React fundamentals, JavaScript concepts, components, state management, event handling, and React Hooks.

## Features

### To-Do App

- Add new tasks
- Mark tasks as completed
- Edit tasks
- Delete tasks
- Save tasks using Local Storage
- Responsive user interface

### Notes App

- Create notes
- View notes
- Edit notes
- Delete notes
- Search notes
- Save notes using Local Storage
- Responsive user interface
